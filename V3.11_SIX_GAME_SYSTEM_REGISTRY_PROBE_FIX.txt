v3.11 six-game System registry probe fix

3. No WebSocket/System.register/Map/WeakMap/fetch/XHR patching is added to the normal game runtime.
4. Hidden probe posts progress stages and is destroyed after one bounded snapshot.
5. Existing cleanup/session TTL protections remain.
