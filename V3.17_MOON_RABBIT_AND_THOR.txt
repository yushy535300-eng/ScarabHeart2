聖甲之心助手 v3.17

新增遊戲
- TZ 遊戲中心新增月兔（QT）與雷神（RSG）遊戲卡。
- 依 TZ 登入回傳的遊戲入口在程式畫面內開啟；這兩款不進 ATG 推薦機台頁。
- 遊戲回應非成功、入口網址不符或服務維護時，畫面會顯示回傳錯誤並留在遊戲中心。

遊戲內工具
- 月兔載入月兔遊戲工具，讀取可取得的本場輸贏、餘額、單轉結果與特色計量，並提供倍率及結果提示控制。
- 雷神載入雷神遊戲工具與浮動工具適配層；狀態、倍率及防護操作依遊戲引擎實際支援提供。
- 月兔和雷神不會使用 ATG 的房間推薦、roomId 或自動選房功能。
- 外層遊戲畫面使用聖甲之心 logo、遊戲卡與品牌標示。

相容性與驗證
- TZ QT/RSG 登入請求欄位依使用者提供的成功請求紀錄設定。
- 月兔、雷神的遊戲網域使用明確主機白名單及各自的遊戲工作階段代理；WebSocket 只允許該款遊戲紀錄內的主機。
- npm run check 驗證 JavaScript 語法。
- 未使用真人 TZ 帳號連上正式服務驗證，實際登入後仍需在部署環境確認遊戲載入與遊戲內工具狀態。

原 v3.16 資料夾和壓縮檔保持未修改。
