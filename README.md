# ScarabHeart Web v2.49

可直接上傳 GitHub 並連接 Render 的網頁版本。

## Render

- Root Directory：`web-render`
- Build Command：`npm install`
- Start Command：`npm start`

遊戲以同頁全螢幕容器開啟，既有 ATG／RSG 引擎、懸浮介面、加速、FREE 自動、劇透、停利停損及機台控制沿用 iOS v2.45。

## 響應式畫面

- 手機：維持原本直式登入、單欄機台分析與觸控尺寸。
- 電腦：獨立左右式登入畫面，遊戲中心與機台分析放寬置中，不拉伸手機素材。
